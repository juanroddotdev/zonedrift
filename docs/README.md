# GitHub Pages setup

Host the privacy policy for the Chrome Web Store listing.

## Enable Pages

1. Open [github.com/juanroddotdev/zonedrift/settings/pages](https://github.com/juanroddotdev/zonedrift/settings/pages)
2. Under **Build and deployment** → **Source**, choose **Deploy from a branch**
3. Branch: **main**, folder: **/docs**
4. Save

After a minute or two, the policy will be live at:

**https://juanroddotdev.github.io/zonedrift/privacy-policy**

Use that URL in the Chrome Web Store **Privacy policy** field.
